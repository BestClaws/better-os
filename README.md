# Better OS

Lighweight smart watch operating system

* supports BLE connectivity
* HTTP over Bluetooth
* App ecosystem
* Application window compositing (enables split screen, screenshot capabilities)
* Dynamic display resolution
* low system requirements (400KB ram, 150Mhz CPU)
